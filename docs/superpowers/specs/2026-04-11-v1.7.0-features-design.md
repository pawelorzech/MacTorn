# MacTorn v1.7.0 Design Spec

## Overview

Four features for v1.7.0, building on existing infrastructure. All follow established patterns (UserDefaults persistence, NotificationManager, BrowserManager, TimelineView for live countdowns, MockNetworkSession for tests).

## Feature 1: Bazaar Price Alerts

**Goal:** Notify when a watchlist item's price drops below a user-set threshold.

**Model change:** Add `priceThreshold: Int?` to existing `WatchlistItem` struct (TornModels.swift). No new model needed.

**Logic:** In `AppState.fetchItemPrice()`, after updating the price, compare `lowestPrice` against `priceThreshold`. If `lowestPrice <= priceThreshold` and threshold is set, fire a notification via `NotificationManager`. Track `lastAlertedPrice: Int?` on the item to avoid re-firing the same alert on every poll.

**Notification:** New `.priceAlert` case in `NotificationType`. Title: "Price Alert: {itemName}", Body: "Price dropped to ${lowestPrice} (threshold: ${threshold})".

**UI:** In `WatchlistView`, add a button per item to set/edit threshold. Use a popover with a TextField for the price. Display the threshold under the price when set. Show a bell icon when threshold is active.

**Tests:**
- `testPriceAlertTriggered_whenPriceBelowThreshold`
- `testPriceAlertNotTriggered_whenPriceAboveThreshold`
- `testPriceAlertNotRepeated_whenAlreadyAlerted`
- `testPriceThreshold_persistedWithWatchlist`

## Feature 2: OC Timer

**Goal:** Show active Organized Crime status with live countdown in Faction tab.

**API change:** Faction endpoint selections: `basic,chain` → `basic,chain,crimes`. The v1 faction API returns OC data under the `crimes` key.

**Model:** New `OrganizedCrime` struct:
```swift
struct OrganizedCrime: Codable, Identifiable {
    let id: Int
    let crimeId: Int
    let crimeName: String
    let participants: [OCParticipant]
    let timeStarted: Int
    let timeReady: Int
    let timeLeft: Int
    let initiated: Bool
    let plannerName: String?
    let plannerId: Int?
}

struct OCParticipant: Codable {
    let description: String?
    let state: String? // "Okay", etc
}
```

Add `crimes: [String: OrganizedCrime]?` to `FactionData` parsing in `fetchFactionData()`.

**UI:** New `OCStatusView` section in `FactionView`, below chain. Shows:
- Crime name and planner
- Live countdown using `TimelineView` (same pattern as `LiveCooldownItem`)
- Green "READY" badge when `timeLeft == 0 && initiated`
- Participant count

**Notification:** New `.ocReady` type. Fires when OC becomes ready (timeLeft transitions from >0 to 0).

**Tests:**
- `testFetchFactionData_parsesCrimes`
- `testOCTimeRemaining_calculatesCorrectly`
- Model decoding tests for OrganizedCrime

## Feature 3: Net Worth Dashboard

**Goal:** Replace basic MoneyView with comprehensive net worth breakdown.

**API change:** Add `stocks` to user API selections string.

**New model:**
```swift
struct StockHolding: Codable {
    let stockId: Int
    let totalShares: Int
    let transactions: [StockTransaction]?
}

struct StockTransaction: Codable {
    let shares: Int
    let boughtPrice: Int
    let timeBought: Int
}
```

**Parsing:** In `parseDataInBackground()`, extract `stocks` dictionary from JSON. Map to `[StockHolding]`. Store in new `@Published var stocksData: [StockHolding]?` on AppState.

**Note on stock prices:** The user API returns shares owned and purchase price but NOT current market price. Current prices require a separate Torn API call (`/torn/?selections=stocks`). For v1.7.0, show shares owned and cost basis. Current value can be a follow-up.

**UI overhaul of MoneyView:**
- Section: "Cash" — cash on hand, vault, Cayman (existing)
- Section: "Properties" — list each property with vault amount (data already fetched in `propertiesData`)
- Section: "Stocks" — list holdings with shares and cost basis
- Section: "Points" — point count (existing)
- Footer: "Total Tracked" — sum of cash + vault + Cayman + property vaults + stock cost basis

**Tests:**
- `testParseStocksData`
- `testNetWorthCalculation`
- Model decoding tests

## Feature 4: The Masters Hub Quick Link

**Goal:** One-click access to hub.tri.ovh from the app.

**Implementation:** Add "TRI Hub" to the Quick Links section in `StatusView`. Uses existing `BrowserManager.shared.open(url)` pattern. URL: `https://hub.tri.ovh`

**UI:** New button in `quickLinksSection` LazyVGrid with globe icon. Visually distinct (slightly different color/style) to stand out from Torn.com links.

**No tests needed** — trivial UI link, follows existing pattern exactly.

## Architecture Notes

- No new files for models — extend existing TornModels.swift
- No new ViewModels — extend AppState
- New view files: None needed. Extend FactionView (OC section) and MoneyView (net worth). WatchlistView gets threshold UI.
- Test files: Extend existing test files + new model tests as needed
- All persistence via UserDefaults (existing pattern)
- All notifications via NotificationManager (existing pattern)
